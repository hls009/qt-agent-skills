# Qt 5 CMake facts, checked against <Qt5>/lib/cmake instead of the headers.
#
# A bare name is asserted to EXIST in the kit (a macro, a package directory or an
# imported target). A name prefixed with "!" is asserted NOT to exist — those are
# the Qt 6 commands the skills forbid, plus the plausible target names that were
# never shipped. Both directions matter: this fork's central claim is that the Qt 6
# spelling is undefined in Qt 5, and a wrong "does not exist" sentence sends users
# hunting for a module their kit does ship (audit P0-12).
